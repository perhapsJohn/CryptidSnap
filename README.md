# Cryptid Snap (web build)

Drive a wood-panel station wagon through Hollow Pines County on Halloween
night, 1986, and photograph the cryptids nobody believes in. Godot 4.6.

This repository holds only the exported web build, served by GitHub Pages at
https://perhapsjohn.github.io/CryptidSnap/ and played in the Wayside Station
arcade. Phones load `index.mobile.pck`, desktops `index.pck`. Online CB Rally
goes through the Wayside relay. The source lives elsewhere.
